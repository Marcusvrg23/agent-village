# Site da Agent Village

Página única e estática (`index.html` + `assets/`), sem build e sem dependências. Para ver localmente, abra `index.html` no navegador.

Publicar (precisa da autorização do dono do projeto):
- **GitHub Pages:** em Settings › Pages do repositório, escolha a branch e a pasta `/site`. Em repositório privado, o Pages exige plano pago do GitHub; com o repositório público é gratuito.
- **Qualquer hospedagem estática** (Square Cloud, Netlify, Cloudflare Pages): envie o conteúdo desta pasta.

Os comandos de instalação da página usam `git clone https://github.com/Marcusvrg23/agent-village.git`, que só funciona para outras pessoas quando o repositório estiver público.
