# Site da Agent Village

Página única e estática (`index.html` + `assets/`), sem build e sem dependências. Para ver localmente, abra `index.html` no navegador.

Publicar (precisa da autorização do dono do projeto):
- **GitHub Pages (automático):** `.github/workflows/pages.yml` publica esta pasta a cada mudança na `main`. Uma vez só: Settings › Pages › Source: "GitHub Actions". Endereço: https://marcusvrg23.github.io/agent-village/
- **Qualquer hospedagem estática** (Square Cloud, Netlify, Cloudflare Pages): envie o conteúdo desta pasta.
