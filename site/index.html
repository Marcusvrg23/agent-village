Resposta do hook:

(esperando sua decisão)

  1. Um comando, uma vez

    npm run village:setup -- hooks install --yes instala o hook de permissão em cada conta do Claude Code e do Codex, com backup antes.

  2. O agente pede, a vila mostra

    O cartão diz o que ele quer: o comando, o arquivo ou a página. Ligue o 🔔 para ouvir um aviso.

Firewall financeiro

US$ 0,00

Gasto de API autorizado por padrão. A vila usa só o login do seu plano.

Feita para quem paga plano, não API

  • Antes de rodar qualquer missão, confere que o Claude Code está logado pela assinatura e que o Codex está logado pelo ChatGPT.
  • Login por chave de API ou desconhecido: a missão é bloqueada.
  • Variáveis como ANTHROPIC_API_KEY e OPENAI_API_KEY são removidas dos processos dos agentes.
  • Cota esgotada: a missão espera a renovação ou vai para outra conta sua, nunca para uma API paga.
  • A vida da vila (passeios, conversas, jogos) não chama IA nenhuma: 0 tokens.
Portão de entrada

Instalar

Gratuito e local: tudo roda no seu computador. Precisa do Node.js 20 ou mais novo e do Claude Code e/ou do Codex já logados.

No Prompt de Comando ou no PowerShell:

git clone https://github.com/Marcusvrg23/agent-village.git
cd agent-village
npm run village

A vila abre em http://127.0.0.1:4173/village/ com a execução de missões ligada; cada missão só roda depois do seu clique em Aprovar.

No Terminal:

git clone https://github.com/Marcusvrg23/agent-village.git
cd agent-village
npm run village

A execução de missões já vem ligada; cada missão só roda depois do seu clique em Aprovar.

git clone https://github.com/Marcusvrg23/agent-village.git
cd agent-village
npm run village

A execução de missões já vem ligada; cada missão só roda depois do seu clique em Aprovar.

git clone https://github.com/Marcusvrg23/agent-village.git
cd agent-village
docker compose up -d

No Docker a vila só observa (missões ficam desligadas, porque os agentes e os logins ficam no seu computador). Entram no container, somente leitura, só as pastas de sessões. No Windows, antes: set VILLAGE_HOST_HOME=%USERPROFILE%.

Depois de instalar (opcional, uma vez)

npm run village:setup -- hooks install --yes
npm run village:setup -- statusline install --yes

O primeiro liga a mão levantada (pedidos de permissão na vila). O segundo deixa a vila ler a cota do Claude. Os dois mostram uma prévia sem --yes e fazem backup antes de mudar qualquer configuração. No Codex, aprove o hook uma vez em /hooks.

Context Vault

Seus dados ficam no seu computador

A vila lê as sessões que o Claude Code e o Codex já gravam, sem alterá-las, e mostra só o nome da ferramenta e do arquivo, nunca o texto dos seus prompts.

  • Nunca abre credenciais: nada de auth.json, chaveiro ou tokens.
  • O servidor escuta só em 127.0.0.1; o celular usa uma porta separada, opcional, com código de pareamento.
  • Os hooks falam só com o seu computador, com um segredo novo a cada vez que a vila abre.
  • Missões, histórico e auditoria ficam em ~/.agent-village, com segredos mascarados.
Perguntas

Perguntas frequentes

Precisa pagar alguma coisa?

Não. A vila é gratuita e usa o plano que você já tem (Claude Pro/Max, ChatGPT Plus). Por padrão ela não gasta nada de API.

Funciona só com o Claude Code, ou só com o Codex?

Funciona com qualquer um dos dois, ou com os dois juntos. Sem nenhum deles instalado, a vila abre e mostra a vida dos moradores, mas sem agentes reais.

A vila aprova coisas sozinha?

Não. Cada aprovação vem de um clique seu. Se a vila estiver fechada, o pedido segue para o terminal como sempre.

Roda em computador fraco?

Sim. Foi feita num notebook de 2013 com vídeo integrado e roda a 30 quadros por segundo. Se ficar lento, os efeitos diminuem sozinhos.

Posso usar minha própria arte?

Pode, pelo botão 🎨, desde que seja sua ou licenciada e não use personagens, marcas ou pessoas reais de terceiros. O formato está na política de arte do projeto.
